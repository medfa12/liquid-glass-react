Why the backdrop is an image

The effect displaces where each fragment samples the backdrop. Browsers deliberately do not expose live backdrop pixels to WebGL, and backdrop-filter has no hook to move a sample position. So the backdrop is supplied explicitly — here, a static test pattern.

Fidelity

Verified against a real NSGlassEffectView capture on macOS 26.5.2: 34.4 dB on the element interior, 19.9 dB overall. The rim is the weak spot — corner shape and the outermost specular.

Requires

WebGL2. There is no WebGL1 path: the blur is textureLod() against a mip chain, which WebGL1 cannot express.
